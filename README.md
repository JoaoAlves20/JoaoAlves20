Meus projetos simulam cenários reais e aplicam boas práticas como **arquitetura em camadas** (routes → controllers → services), **validação de dados com Zod**, **autenticação JWT**, **ORM com Prisma** e **testes automatizados**.

- 🎯 Objetivo: evoluir como desenvolvedor backend, dominando tecnologias modernas e construindo soluções escaláveis e eficientes
- 💬 Pode falar comigo sobre Node.js, TypeScript, APIs REST e bancos de dados
